# GAZE (가제)

SCP 소재의 탑다운 도트 호러 웹 게임. 173은 계속 쳐다봐야 살고, 096은 쳐다보면 안 된다. 기획은 `docs/spec.md`, 버전 계획은 `docs/roadmap.md`, 결정 기록은 `docs/decisions.md`.

**현재 버전: v0.4 — 무전·신뢰·엔딩** (시드로 만든 4개 구역, SCP-173과 SCP-096, 여닫는 문, 곁방 지시·거짓 무전·엔딩 4개, 임시 도형 에셋)

## 조작

| 입력 | 동작 |
|---|---|
| WASD | 이동 |
| 마우스 | 시선 조준 (시야 콘이 커서 방향을 향함) |
| Shift | 달리기 (스태미너 소모) |
| E | 가까운 문(24px 이내) 열림 → 닫힘 → 잠김 → 열림. 카드키를 들고 마지막 구역 출구 앞이면 출구가 먼저 열린다 |
| Q | 안약: 눈 깜빡임 게이지를 0으로 |
| F | 각성제: 스태미너 즉시 가득 + 5초 동안 안 닳음 |
| Space | 사망 후 그 구역 입구에서 다시 / 엔딩 화면에서 새 판 |
| R (3초 안에 두 번) | 새 판 시작 (지금 진행 삭제). 한 번만 누르거나 누르고 있으면 경고만 뜬다 |
| M (`?debug=1`일 때만) | 안개 끄기 + 시드·구역·시도 표시 |

규칙: 한 판은 4개 구역이다. 구역 끝의 초록 문으로 걸어 들어가면 다음 구역으로 넘어간다. 2~3번째 구역 중 한 곳에 카드키(노란 점)가 있고, 그 구역의 문은 카드키를 주워야 열린다(그전엔 붉은 문). 마지막 구역의 붉은 출구에서 E를 누르면 탈출. 173은 **시야 콘 안에 있으면 멈추고**, 벗어나거나 눈이 깜빡이는 순간 달려든다. 첫 구역의 173은 한 번 보기 전까지 움직이지 않고, 이후 구역의 173은 14타일 안으로 다가오면 쫓아온다. 눈 깜빡임 게이지(하단 "눈")가 차면 강제로 눈이 감긴다.

**문 (v0.3)**: 통로가 방에 들어가는 폭 2 입구마다 문이 있고 처음엔 열려 있다(테두리만 보임). 닫힌 문(갈색)과 잠긴 문(붉은 갈색 + 가운데 점)은 이동과 시선을 막는다. 누가 문 칸에 서 있으면 안 닫힌다. 173은 닫히거나 잠긴 문도 그냥 열고 지나가니, 173 앞에서 문을 닫으면 오히려 안 보이게 될 뿐이다.

**SCP-096 (v0.3)**: 3·4번째 구역에 한 마리씩 앉아 있다. 정면(096이 향한 쪽 ±60°)에서 **얼굴을 보면** 화면이 흔들리고 폭주해서 플레이어보다 빠르게 쫓아온다. 뒤나 옆에서 보는 건 괜찮고, 닫힌 문 너머나 눈 깜빡이는 동안은 안 보인 것으로 친다. 폭주한 096은 닫힌 문을 3초, 잠긴 문을 6초 걸려 부순다(부서진 문은 다시 못 닫음). 잠긴 문을 부수는 동안 그 문에서 경로 20타일 넘게 떨어지면 진정하고 제자리로 돌아간다. 다음 구역으로 넘어가도 따라오지 않는다. 처음 가까이(경로 12타일) 가면 관제실이 경고한다.

**곁방 지시 (v0.4)**: 구역마다 막다른 곁방이 하나 있다. 곁방 문 가까이(경로 12타일, 곁방이 길에서 멀면 길이 가장 가까워지는 지점) 오면 관제실이 "〈방향〉 곁방에 〈아이템〉이 있다. 가져가라." 뒤에 규칙 한 마디를 붙여 지시한다. 첫 구역은 항상 진실이고, 2~4번째 구역 중 1~2개는 **거짓**이다. 거짓 지시에 붙은 규칙은 첫 구역에서 배운 173·깜빡임 규칙과 맞지 않는다 — 그게 단서다. 진실 곁방엔 안약이나 각성제가 있고, 거짓 곁방에 들어가면 문이 잠겨 8초 동안 갇히고 1.5초 정전(아무것도 안 보이니 173이 움직인다)과 함께 무언가 번쩍인다. 곁방에 들어갔는지(지시를 따랐는지)는 구역을 나갈 때 확정되고, 탈출하면 판 전체의 선택에 따라 엔딩 4개(분별 · 혼자 걷다 · 반쪽의 목소리 · 충실한 D급) 중 하나가 나온다. 본 엔딩은 따로 저장된다(`gaze.endings.v1`). 신뢰도 숫자는 어디에도 나오지 않는다.

죽으면 그 구역만 새로 만들어지고 입구에서 다시 시작한다. 진행(구역, 카드키, 아이템, 구역별 지시 결과, 들은 무전)은 브라우저(`localStorage`, 키 `gaze.run.v1`)에 저장되어, 페이지를 다시 열면 마지막으로 들어간 구역부터 이어진다. 주소 끝에 `?seed=12345`를 붙여 열면 그 시드로 새 판을 시작하고, 주소에서 `seed`는 바로 지워져서 새로고침하면 그 판이 이어진다.

## 실행

빌드 도구 없음. 저장소 루트에서 정적 서버를 띄우면 된다.

```bash
python3 -m http.server 8000
```

`http://localhost:8000` 접속. (`file://`로 직접 열면 ES module이 막힌다.)

GitHub Pages로도 그대로 열린다 (모든 경로가 상대 경로).

## 테스트

```bash
npm test          # 순수 로직 단위 테스트 (node --test, 추가 설치 불필요)
npm install && npx playwright install chromium   # 스모크 테스트를 처음 돌릴 때 한 번
npm run smoke     # Playwright 스모크 테스트 (브라우저에서 실제 씬 확인, python3 필요)
```

- `src/logic/` — DOM·Phaser를 모르는 순수 규칙(이동 충돌, 시야, 173, 096, 문, 스태미너, 깜빡임, 무전, 지시·엔딩·아이템·함정, 맵 파서·생성기). 단위 테스트 대상.
- `src/scenes/`, `src/render/`, `src/audio/` — Phaser 연결·그리기. 스모크 테스트 대상.
- 스모크 테스트는 `?debug=1`일 때만 켜지는 `window.__debug` 훅(`src/debug.js`)으로 씬 상태를 읽고 조작한다.
