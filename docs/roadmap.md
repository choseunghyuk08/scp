# 로드맵 (roadmap)

규칙: 한 버전 = 끝에 **실제로 플레이 가능**해야 한다. 한 버전이 끝나면 체크하고, 다음 버전 들어가기 전에 확인한다. v0.1에서 v0.2 기능을 끼워넣지 않는다.

## v0.1 — 173 재미 검증

목적: "시야 콘 + 깜빡임 게이지 + 173" 하나만으로 긴장이 생기는지 확인한다. 안 생기면 여기서 방향을 튼다.

- [ ] 프로젝트 골격: `index.html`, `vendor/phaser.min.js`(3.90.0), 실행 방법(README)
- [ ] 고정 테스트 맵 (방 4개, 타일맵 데이터)
- [ ] 이동 (WASD), 달리기 + 스태미너 (Shift), 마우스 시선 조준
- [ ] 시야 콘: 벽에 가려지는 레이캐스트, 콘 밖 어둡게
- [ ] SCP-173: 콘 안 정지 / 콘 밖 추격, 접촉 사망
- [ ] 눈 깜빡임 게이지 + 강제 깜빡임
- [ ] 카드키 줍기, 출구 문 열기 (E)
- [ ] 최소 무전 텍스트 박스 (진실만 3~4줄: 조작, 173 규칙, 목표)
- [ ] 사망 시 맵 처음부터 재시작
- [ ] 임시 에셋(색 도형) + 임시 beep음

**완료 기준**: 설명 없이 처음 하는 사람이 3판 안에 173 규칙을 이해한다. 한 판 2~3분. 깜빡임 게이지가 찰 때 긴장이 느껴진다 (나 + 지인 1~2명 플레이).

## v0.2 — 절차 생성 + 구역 체크포인트

- [ ] MapGenerator: 구역 4 × 방 3~4개, 방 크기 랜덤, 복도 연결
- [ ] BFS 도달성 검증 + 실패 시 재생성
- [ ] 시드 번호 표시·재현, 디버그 맵 뷰
- [ ] 개체·카드키 배치 규칙 (시작 방과의 거리, 겹침 방지)
- [ ] 구역 체크포인트 (사망 시 구역 입구 재시작, `localStorage` 저장)
- [ ] 첫 구역 = 튜토리얼 구역

**완료 기준**: 시드 100개 자동 검증에서 카드키·출구 도달 실패 0건. 한 판이 약 10분 길이로 체감된다.

## v0.3 — SCP-096 + 문

- [ ] 096: 앉아서 우는 상태, 시야 콘에 얼굴이 들어오면 폭주, 접촉 사망
- [ ] 문 닫기·잠금 (E), 096이 문을 부수는 시간
- [ ] 폭주 따돌리기: 문 / 다음 구역 이동 시 포기
- [ ] 173 + 096 동시 시야 규칙
- [ ] 096 방 배치 규칙을 맵 생성에 추가

**완료 기준**: 096 방을 지나갈 때 "안 보려고 시선을 돌리는" 행동이 자연스럽게 나온다. 문으로 폭주를 따돌릴 수 있다.

## v0.4 — 무전·신뢰·엔딩

- [ ] 관제 AI 무전 시스템: 이동 지시 + 규칙 정보
- [ ] 구역 1은 진실만, 구역 2부터 거짓 1~2개 (단서로 간파 가능)
- [ ] 신뢰도 계산 (이동 지시를 따랐는지 판정)
- [ ] 엔딩 3종 + 엔딩 화면 + 본 엔딩 저장
- [ ] 속임수 스케어 (임시 연출)
- [ ] (여유 시) 4번째 '분별' 엔딩

**완료 기준**: 거짓 무전을 단서로 간파할 수 있다 (테스트 플레이어 2명 확인). 엔딩 3종 모두 도달 가능.

## v0.5 — 아트·사운드·점프스케어

- [ ] 스프라이트 생성 스크립트(Pillow) → PNG 시트: 플레이어 4방향 걷기, 173, 096(평상/폭주), 타일셋, UI
- [ ] 합성음(Web Audio): 173 긁는 소리, 096 울음·폭주, 무전 노이즈, 환경 드론, 점프스케어
- [ ] 개체별 사망 컷 + 화면 흔들림 + 글리치
- [ ] 속임수 스케어 완성 (번쩍임 초당 3회 이하)

**완료 기준**: 임시 도형 에셋 0개. 모든 소리가 합성음으로 대체. 같은 파일명으로 교체하면 반영되는 구조.
