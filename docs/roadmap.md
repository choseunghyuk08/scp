# 로드맵 (roadmap)

규칙: 한 버전 = 끝에 **실제로 플레이 가능**해야 한다. 한 버전이 끝나면 체크하고, 다음 버전 들어가기 전에 확인한다. v0.1에서 v0.2 기능을 끼워넣지 않는다.

## v0.1 — 173 재미 검증

목적: "시야 콘 + 깜빡임 게이지 + 173" 하나만으로 긴장이 생기는지 확인한다. 안 생기면 여기서 방향을 튼다.

- [x] 프로젝트 골격: `index.html`, `vendor/phaser.min.js`(3.90.0), 실행 방법(README)
- [x] 고정 테스트 맵 (방 4개, 타일맵 데이터)
- [x] 이동 (WASD), 달리기 + 스태미너 (Shift), 마우스 시선 조준
- [x] 시야 콘: 벽에 가려지는 레이캐스트, 콘 밖 어둡게
- [x] SCP-173: 콘 안 정지 / 콘 밖 추격, 접촉 사망
- [x] 눈 깜빡임 게이지 + 강제 깜빡임
- [x] 카드키는 닿으면 줍기, 출구 문은 E로 열기
- [x] 최소 무전 텍스트 박스 (진실만 3~4줄: 조작, 173 규칙, 목표)
- [x] 사망 시 맵 처음부터 재시작
- [x] 임시 에셋(색 도형) + 임시 beep음
- [ ] 플레이테스트 (사용자): 아래 완료 기준을 직접 확인

**완료 기준**: 설명 없이 처음 하는 사람이 3판 안에 173 규칙을 이해한다. 한 판 2~3분. 깜빡임 게이지가 찰 때 긴장이 느껴진다 (나 + 지인 1~2명 플레이).

## v0.2 — 절차 생성 + 구역 체크포인트

- [ ] 시드 난수기 (순수 함수, 같은 시드 → 같은 수열)
- [ ] 구역 생성기: BSP로 방 3~4개(방 크기 랜덤), 폭 2 통로, 기둥 0~2개/방. 출력은 기존 `ParsedMap` 호환 + 구역 출구 문 (D47)
- [ ] BFS 검증 + 재생성 상한 50회 + 고정 맵 폴백 (D46)
- [ ] 개체·카드키 배치 규칙: 173은 입구 방에서 경로 15타일 이상·입구에서 시선 차단, 카드키는 2~3번째 구역에 하나, 출구는 마지막 구역
- [ ] 173 활성화: 튜토리얼 구역은 첫 목격까지 휴면, 이후 구역은 경로 거리 14타일 이내에서만 추격 (D45, D40 해결)
- [ ] 판 상태(Run: 시드·구역·시도·키·들은 무전)와 구역 전환: 구역 끝 문 → 암전 → 다음 구역 (D41, D42)
- [ ] 구역 체크포인트: 사망 시 구역 입구에서 시도 횟수 +1로 그 구역만 재생성, `localStorage` 저장·자동 이어하기·R키 새 판 (D43, D44)
- [ ] 첫 구역 = 튜토리얼: 방 3개, 173 1마리, 카드키 없음, 무전 진실만
- [ ] 들은 무전 줄은 판 안에서 반복하지 않음 (D48)
- [ ] 시드 재현: `?seed=<숫자>`, 디버그 M키 뷰(안개 끔, 시드·구역·시도 횟수 표시)

**완료 기준 (D49)**:
1. 자동: 시드 1000개 × 구역 4개에서 도달성 검증 실패 0건이고 폴백 사용 0건. 평균·최대 시도 횟수를 보고한다.
2. 자동: 같은 시드 → 같은 맵(결정성).
3. 자동: 시작→카드키→출구 최단 경로 합계 450타일 이상.
4. 자동: 구역 전환, 사망 후 구역 입구 재시작(키 유지), 새로고침 이어하기, R키 새 판이 스모크 체크를 통과한다.
5. 사용자 플레이테스트: 한 판이 약 10분으로 체감된다. 첫 구역에서 173을 본 뒤에 죽는다 (D40 해소 확인).
