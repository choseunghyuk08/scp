# v0.1 — 173 재미 검증 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 고정 테스트 맵에서 "시야 콘 + 눈 깜빡임 게이지 + SCP-173"만으로 긴장이 생기는지 확인할 수 있는, 처음부터 끝(탈출)까지 플레이 가능한 웹 프로토타입을 만든다.

**Architecture:** 게임 규칙은 DOM·Phaser를 모르는 순수 함수 모듈(`src/logic/`)로 만들고 `node --test`로 검증한다. Phaser 씬(`src/scenes/PlayScene.js`)은 그 모듈을 연결해 그리기만 하고, Playwright 스모크 테스트가 씬을 검증한다. 시야 어둠은 2D 캔버스 오버레이(CanvasTexture)에 시야 다각형을 `destination-out`으로 도려내어 만든다.

**Tech Stack:** Phaser 3.90.0 (MIT, `vendor/phaser.min.js`), 브라우저 ES modules, Node 22 (`node --test`), Playwright (스모크), 빌드 도구 없음.

**Spec:** `docs/spec.md` (§5 조작, §6 시야, §7 SCP-173, §8 무전, §11 아트·사운드, §14 기술), `docs/roadmap.md` v0.1 섹션

## Global Constraints

- Phaser **3.90.0 (MIT)**를 `vendor/phaser.min.js`로 저장소에 포함. 빌드 도구·번들러 없음. Phaser는 classic `<script>`, 게임 코드는 `<script type="module">`.
- 모든 경로는 **상대 경로** (GitHub Pages 하위 경로 `/scp/`에서도 동작해야 함).
- 렌더러 `Phaser.CANVAS`, `pixelArt: true`, 내부 해상도 **480×270**, 타일 **16×16**, `Scale.FIT`(정수배 확대).
- PC 키보드·마우스 전용: **WASD** 이동, **마우스** 시선 조준, **Shift** 달리기, **E** 상호작용.
- 시야 콘 **70°**(반각 35°), 최대 거리 **8타일(128px)**. 콘 밖은 어둡고, 콘 밖 개체는 보이지 않는다.
- 플레이어 걷기 **48** / 달리기 **80** px/s. 스태미너: 달리기 **4초**, 정지 후 **3초** 뒤 회복 시작.
- 눈 깜빡임 게이지 약 **6초**에 가득, 강제 깜빡임 **0.4초**. 173 추격 속도 **112** px/s, 접촉하면 사망.
- 임시 에셋(색 도형) + 임시 beep음. 무전 텍스트는 진실만. UI 텍스트는 한국어.
- 사망 시 맵 처음부터 재시작. **v0.1에 없는 것**: 절차 생성, 체크포인트, 096, 문 닫기, 거짓 무전, localStorage, 스프라이트.
- 번쩍임(화면 암전)은 초당 3회를 넘지 않는다 (깜빡임 암전은 6초에 1회).
- 결정이 바뀌면 코드만 고치지 말고 `docs/spec.md`·`docs/roadmap.md`와 `docs/decisions.md`도 같이 고친다.

## Review Focus

spec이 암시하지만 개별 태스크 테스트 밖에 있기 쉬운 입력·상황 (각 줄의 테스트는 소유 태스크에 들어 있음):

1. **탭 전환/포커스 이탈 중 키가 눌려 있음** → 돌아오면 캐릭터가 계속 걷는 상태. 기대: 포커스를 잃으면 모든 키가 풀린다. (Task 9)
2. **한 프레임 dt가 매우 큼** (탭이 백그라운드에서 멈췄다 복귀) → 벽을 뚫거나 173이 순간이동. 기대: dt를 0.05초로 제한. (Task 1, 9)
3. **마우스를 한 번도 안 움직임/캔버스 밖** → 시선 각도가 NaN/undefined. 기대: 기본 시선 0rad(오른쪽), NaN 없음. (Task 9)
4. **173이 플레이어에게 갈 길이 없거나 플레이어와 같은 타일에 있음** → 예외 또는 멈춤 버그. 기대: 예외 없음, 길이 없으면 제자리, 같은 타일이면 곧바로 접촉 판정. (Task 6)
5. **죽고 Space로 여러 번 재시작** → 입력 리스너가 중복돼 이동이 2배가 되거나 이전 판 상태가 남음. 기대: 3번 재시작해도 새 판과 동일. (Task 10)
