# 기획서 (spec)

> 가제: **시선 (GAZE)** — 수용 실패 사태에서 D급 인원으로 탈출하는 탑다운 도트 호러
> 작성일: 2026-10-30 · 상태: 기획 확정 대기 (사용자 검토 전)
> 표기: **[확정]** 사용자가 직접 고른 것 / **[가정]** 비어 있어 추천값으로 채운 것 (맨 아래 목록 참고)

## 1. 한 줄 컨셉

173은 **계속 쳐다봐야** 살고, 096은 **절대 쳐다보면 안 된다.** 시선을 관리하며 SCP 수용소를 탈출하는 호러. 길을 알려주는 관제실 무전은 거짓말을 섞는다.

## 2. 목적과 성공 기준 [확정]

- 포트폴리오·공유용. 링크 하나로 열려서 바로 플레이되는 웹 게임 (GitHub Pages 무료 배포, 서버 없음).
- 성공 기준: 링크를 받은 사람이 설명 없이 3판 안에 규칙을 이해하고, 시작부터 엔딩 하나까지 볼 수 있다.
- 소재는 **원작 SCP만** 사용. 위키 텍스트를 가공한 부분은 출처 표기와 동일 조건 공유(CC BY-SA 3.0)가 필요하다. 위키 이미지는 파일마다 라이선스가 달라서 쓰지 않는다.
- 비슷한 게임 'SCP: Containment Breach'와의 차별점: 탑다운 도트, 시선 관리 규칙, 거짓말하는 무전.

## 3. 세계관 [확정/가정]

- 재단 시설이 정전되면서 SCP들이 수용 실패(탈출)한 상황. 플레이어는 D급 인원 [가정: D-9341].
- 관제실 무전 목소리는 **오염된 관제 AI** [확정]. 원작 SCP-079가 시설 통신망을 장악한 것으로 설정 [가정]. D급을 탈출시키는 척하면서 위험한 쪽으로 유도한다.
- 목표: 시설 어딘가의 **카드키**를 찾아 **출구**를 연다.

## 4. 게임 구조 [확정]

- **반복형**: 죽으면 다시 시작. 맵은 **완전 절차 생성**(방 크기도 랜덤).
- **한 판 약 10분, 방 12개 이상**. 맵은 3~4개 **구역**으로 나뉜다 [가정: 4구역 × 방 3~4개].
- **구역 체크포인트**: 구역을 통과하면 저장되고, 죽으면 그 구역 입구에서 재시작한다. 구역 안의 배치는 다시 랜덤.
- **첫 구역은 튜토리얼**: 무전이 진실만 말한다. 조작과 173 규칙을 여기서 배운다. 두 번째 구역부터 거짓말이 섞인다.
- 아이템·스탯 수집은 없다 (아이작식 구조를 피하기 위함). 선택의 재미는 **무전을 믿을지 말지**에 있다.

## 5. 조작과 플레이어 행동 [확정]

PC 키보드·마우스 전용. 모바일에서 열면 "PC에서 플레이하세요" 안내 화면.

| 입력 | 동작 | 버전 |

| 로커 앞 E | 숨기 | v0.6 |

## 6. 시야 시스템 (게임의 심장)

- 플레이어 앞에 **시야 콘**(부채꼴)이 있다. 벽은 시야를 가린다 (레이캐스트).
- 콘 밖은 어둡다. 콘 안에 들어온 개체만 보인다. 콘 밖에 있는 개체는 보이지 않고 소리로만 존재가 느껴진다.
- 173과 096 규칙은 모두 이 시야 콘 판정 하나를 공유한다.
- 초기값(플레이테스트로 조정): 콘 각도 70°, 최대 거리 8타일.

## 7. 개체 규칙 [확정]

### SCP-173 (v0.1)
- 시야 콘 안에 있으면 **정지**. 콘 밖이면 플레이어를 **추격** (플레이어 달리기보다 빠름).
- **눈 깜빡임 게이지**: 계속 차오르고, 가득 차면 강제로 눈이 감긴다. 그 짧은 시간(약 0.4초) 동안 시야가 없어서 173이 도약한다. 게이지는 깜빡임 후 리셋.
- 접촉하면 사망.
- 문 뒤에 있는 173을 보려면 문을 열어야 한다 (v0.3 이후 문과 결합).

### SCP-096 (v0.3)
- 평소에는 얼굴을 가리고 앉아 운다. 정지 상태.
- 시야 콘 안에 096의 **얼굴이 들어오면 폭주**. 얼굴 판정은 096이 향한 방향 기준.
- 폭주하면 매우 빠르게 추격. **닫은 문**은 부수는 데 시간이 걸리고(잠그면 더 오래), **다음 구역으로 넘어가면** 포기한다. 즉사만 있는 구조가 아니라 대응 여지가 있다 [확정].
- 접촉하면 사망.
- 173과 096이 동시에 시야 콘 안에 있으면 173은 정지하고 096은 폭주한다.

### 후속 개체 [가정: v0.6 이후]
- SCP-939 (소리에 반응), SCP-106 (벽 통과), SCP-049 (접근하면 사망). 우선순위 순서는 939 → 106 → 049.

### 초기 수치 (모두 플레이테스트로 조정)

| 항목 | 값 |
|---|---|
| 플레이어 걷기 / 달리기 | 48 / 80 px/s |
| 스태미너 | 달리기 4초, 정지 후 3초 뒤 회복 시작 |
| 173 추격 속도 | 112 px/s |
| 깜빡임 게이지 | 약 6초에 가득, 강제 깜빡임 0.4초 |
| 096 폭주 속도 | 150 px/s |
| 096 문 부수기 | 닫음 3초 / 잠금 6초 |

## 8. 무전 시스템 [확정, 상세는 가정]

- 관제 AI가 텍스트 박스 + 노이즈음으로 말한다. 내용은 두 종류:
  1. **이동 지시**: "동쪽 문으로 가라"처럼 따를 수 있는 행동.
  2. **규칙 정보**: "173은 눈을 마주쳐도 안전하다" 같은 SCP 정보. **거짓이 섞인다.**
- **공정성 원칙**: 모든 거짓 정보는 같은 판 안에서 최소 하나의 단서로 간파할 수 있어야 한다. 단서 종류: (a) 말투·노이즈가 달라짐 (b) 방에서 발견한 메모와 모순 (c) 첫 구역에서 배운 진짜 규칙과 모순.
- **신뢰도**: 이동 지시를 따랐는지만 센다 (정보는 행동으로 판정 불가). 지시 장소의 문으로 일정 시간 안에 들어가면 "따름". 플레이어에게 점수는 숨긴다.
- 거짓 무전은 구역 2부터 판당 1~2개.
- v0.1은 진실만 말하는 **최소 무전 박스**만 넣어 튜토리얼을 전달한다 [가정]. 거짓말·신뢰도는 v0.4.

## 9. 엔딩 [확정: 신뢰도 기반 3개 이상, 내용은 가정]

| 엔딩 | 조건 (신뢰도 = 따른 지시 / 전체 지시) | 내용 |
|---|---|---|
| 혼자 걷다 | 33% 이하 | 거의 불신하며 탈출. 목소리의 정체를 의심한 채 문을 나선다. |
| 반쪽의 목소리 | 34~66% | 탈출하지만 어디까지가 진실이었는지 모른다. |
| 충실한 D급 | 67% 이상 | 끝까지 믿었다가 출구 앞에서 AI의 진짜 의도를 마주한다 (배신). |
| (선택) 분별 | 거짓 지시를 모두 거부하고 진실 지시를 대부분 수용 | v0.4에서 여유가 있으면 추가하는 진엔딩 [가정] |

## 10. 맵 생성 [확정: 완전 절차 생성]

- 구역마다 BSP 분할로 방 배치(크기 랜덤) → 복도로 연결 → 시작 방·카드키 방·출구 방 지정.
- **검증**: 시작점에서 BFS로 카드키 방과 출구까지 도달 가능한지 검사. 실패하면 시드를 바꿔 재생성.
- 카드키는 출구 구역 이전에 반드시 존재. 개체는 시작 방에서 일정 거리 이상, 카드키 방과 겹치지 않게 배치.
- 모든 맵은 **시드 번호**로 재현 가능하게 한다. 디버그 모드에서 맵 구조와 시드를 시각화한다.
- v0.1은 절차 생성 없이 **고정 테스트 맵**(방 4개). 절차 생성은 v0.2.

## 11. 아트·사운드 [확정/가정]

- **도트 픽셀아트**. 내부 해상도 480×270, 타일 16×16, 정수배 확대 [가정].
- 스프라이트 시트는 **내가 코드(Python Pillow)로 그려서 PNG로 뽑는다.** AI 이미지나 실사급 디테일은 불가. 같은 파일명으로 덮어쓰면 네가 만든 이미지로 교체된다.
- v0.1~v0.3은 색 도형 임시 에셋 [확정].
- 사운드는 **Web Audio 코드 합성**(노이즈, 저음 드론, 긁는 소리, 비명, 무전 노이즈) + 나중에 교체 [확정].
- 점프스케어 컷은 개체별 큰 도트 컷 + 화면 흔들림 + 글리치 + 합성음.

## 12. 점프스케어 사용 규칙 [확정]

- **사망 순간**에는 개체별로 다른 컷을 쓴다.
- 가끔 **속임수 스케어**: 거짓 무전을 믿었더니 가짜 스케어가 터지는 연출 (v0.4 임시, v0.5 완성).
- 플레이 중에는 소리와 조명 변화로 긴장만 쌓는다.
- 시작 화면에 큰 소리·번쩍임 **경고문**만 넣는다 (강도 옵션 없음) [확정]. 번쩍임은 초당 3회를 넘기지 않게 구현한다.

## 14. 기술 [확정/가정]

- **Phaser 3.90.0 (MIT)**. `vendor/phaser.min.js`로 저장소에 포함, 빌드 도구 없음. (이 환경은 CDN이 막혀 있고 npm은 열려 있어서 npm으로 받아 파일만 복사한다.)
- 로컬 실행: `python3 -m http.server`. 배포: GitHub Pages.
- 서버·DB 없음. 저장은 `localStorage` (체크포인트 구역, 본 엔딩, 설정) [가정].
- 구조(예정):
  ```
  index.html
  vendor/phaser.min.js
  src/scenes/    Warning, Title, Play, Death, Ending, Credits
  src/systems/   vision, entities, radio, mapgen, audio-synth, save
  assets/        sprites/, (오디오는 코드 합성)
  tools/         스프라이트 생성 스크립트 (Python Pillow)
  docs/
  ```

## 16. 가정 목록 (틀리면 알려줘)

1. 관제 AI는 원작 SCP-079로 설정한다.
2. D급 번호는 D-9341.
3. 해상도 480×270, 타일 16×16.
4. 4구역 × 방 3~4개 = 12개 이상.
5. 엔딩 구간(33% / 66%)과 엔딩 이름·내용, 4번째 '분별' 엔딩은 여유 있을 때만.
6. v0.1에도 진실만 말하는 최소 무전 박스를 넣는다.
7. 939·106·049는 v0.6(배포) 이후 순서대로 추가.
8. 저장은 `localStorage`.
9. 개체 속도 등 모든 수치는 초기값이고 플레이테스트로 조정.
10. 가제는 "시선 (GAZE)".
