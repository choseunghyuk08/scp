# 결정 로그 (decisions)

날짜는 모두 2026-10-30. 번호는 결정 순서. 나중에 바뀌면 줄을 지우지 말고 "변경" 줄을 추가한다.

| # | 결정 | 왜 | 대안 (버린 것) |
|---|---|---|---|
| D01 | 목적은 포트폴리오·공유용 웹 게임 | 링크 하나로 바로 플레이, GitHub Pages 무료 배포, 백엔드 불필요 | 혼자 연습용, 스팀/itch 정식 출시 |

| D06 | 매번 방과 배치가 랜덤 | 사용자 선택 | 알게 된 정보가 남는 방식, 같은 상황 결말 수집 |

| D09 | 사운드는 Web Audio 코드 합성 + 나중에 교체 | 내가 녹음 파일은 못 만듦 | 무료 사운드 소스, 사용자 직접 제작 |
| D10 | 임시 에셋으로 먼저 개발 | 에셋 제작이 막혀도 게임이 돌아감 | 에셋 먼저 모으고 개발 |
| D11 | 조작은 탑다운 2D 직접 이동 | 173이 시야 밖에서 다가오는 긴장감 | 장면+선택지(포인트앤클릭), 횡스크롤 |
| D12 | 첫 개체 SCP-173, 시야 규칙은 "시야 콘 + 눈 깜빡임 게이지" | 원작 규칙이 그대로 긴장이 됨 | 시야 콘만, 화면 안이면 정지 |
| D13 | 목표는 카드키를 찾아 출구로 탈출 | 목표가 명확하고 랜덤 배치와 잘 맞음 | 시간 생존, 연속 돌파 |
| D14 | 선택 요소에서 아이템·스탯 제외 (아이작식 거부) | 사용자가 "아이작 같은 게임은 별로"라고 함 | 랜덤 이벤트 방 선택지 |
| D15 | **173 단일이 아니라 SCP 여러 종을 통합한 게임** (사용자: "scp 전체 소재로 통합해서") | 개체마다 다른 규칙이 곧 '규칙 읽는 재미' | 173 전용 게임 |
| D16 | 한 판 방 12개 이상, 약 10분 | 사용자 선택 | 6~9개 3~5분 (내가 추천했음) |
| D17 | 구역 체크포인트로 재시작 | 10분 한 판의 손해를 줄임 | 순수 로그라이크 |
| D18 | 세계관은 수용 실패 사태 속 탈출 | 방마다 다른 SCP가 있는 걸 자연스럽게 설명 | 실험 코스, 구역 등급 상승 |
| D19 | 규칙 전달은 관제실 무전 (거짓말 가능), 단서로 구분 가능한 거짓만 | 믿을지 말지가 곧 선택. 불공정한 사망 방지 | 단말기 문서, 규칙 숨김 |
| D20 | 관제 AI는 SCP에 오염됨 → 원작 SCP-079로 설정 (가정) | 사용자 선택을 원작 SCP만 쓴다는 D02와 양립시킴 | 오염 원인을 새로 창작 |
| D21 | 무전은 이동 지시 + 규칙 정보. 신뢰도는 이동 지시를 따랐는지로 셈 | 판정이 명확해서 엔딩 분기가 쉬움 | 지시만, 정보만 |
| D22 | 엔딩은 신뢰도 기반 3개 이상 | 사용자 선택. 내가 신뢰도 추적 비용이 늘 수 있다고 언급했으나 진행 | 엔딩 2개, 엔딩 1개 |

| D25 | 플레이어 행동: 달리기+스태미너, 문 닫기·잠금, 로커 숨기 (손전등 배터리 제외) | 지형을 이용하는 대응이라 아이템 느낌이 안 남 | 손전등 배터리 |
